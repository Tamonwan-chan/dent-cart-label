# ฉลากยา แผนกทันตกรรม (Dental Label Printer)

Designed & Developed by ภญ.ธมลวรรณ จันทร์แก้ว (โรงพยาบาลสันกำแพง) · © 2569 (2026) สงวนลิขสิทธิ์

**เปิดโปรแกรม: <https://tamonwan-chan.github.io/dent-cart-label/>**

พิมพ์ฉลากยาสำหรับยาที่แบ่งบรรจุไว้ที่แผนกทันตกรรม
บรรทัดบนสุดของฉลาก: **วันที่จัด** (วันที่พิมพ์ อัตโนมัติ) ด้านซ้าย และ **วันหมดอายุ** (ใส่เองก่อนพิมพ์) ด้านขวา
ถ้าไม่ได้ใส่วันหมดอายุ ฉลากจะเว้นเป็นจุดไข่ปลาให้เขียนเอง
ฉลากเว้นจำนวนเม็ด/ครั้ง ให้เขียนเอง (ยกเว้น TA 0.1% ointment ที่พิมพ์วิธีใช้ "ป้ายแผลในปาก" ไว้แล้ว)

ดัดแปลงจาก [er-cart-label](https://github.com/Tamonwan-chan/er-cart-label)

## ไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | โปรแกรมพิมพ์ฉลาก |
| `cart-list.js` | รายการยา (สำรองข้อมูล) — 5 รายการ |

## รายการยา

| ยา | บรรจุ | วิธีใช้บนฉลาก |
| --- | --- | --- |
| Amoxicillin 250 mg | # 20 แคปซูล | เขียนเอง |
| Amoxicillin 500 mg | # 20 แคปซูล | เขียนเอง |
| Clindamycin 300 mg | # 20 แคปซูล | เขียนเอง |
| Paracetamol 500 mg | # 10 เม็ด | ครั้งละ ..... เม็ด ทุก 4 ถึง 6 ชั่วโมง เวลามีอาการปวดหรือไข้ |
| Triamcinolone (TA) 0.1% ointment | # 1 หลอด | ป้ายแผลในปาก |

## วิธีใช้

1. เปิดหน้าเว็บ <https://tamonwan-chan.github.io/dent-cart-label/> หรือดับเบิลคลิก `index.html`
2. ใส่วันหมดอายุของยาล็อตนั้นในช่อง "วันหมดอายุ" (โปรแกรมไม่จำค่า ต้องใส่ใหม่ทุกครั้ง กันพิมพ์วันหมดอายุของล็อตเก่า)
3. เลือกจำนวนฉลากที่ต้องการในช่อง "พิมพ์" ของแต่ละยา
4. กด **พิมพ์ฉลาก** หรือ `Ctrl+Enter`

ตั้งค่าเครื่องพิมพ์ (ครั้งแรก): Xprinter XP-DT427B, กระดาษ 90 × 60 มม., ขอบกระดาษ (Margins) = None, Scale 100%

## แก้ไขรายการยาและสำรองข้อมูล

1. กด **ผู้ดูแล** → ใส่ PIN → แท็บ "รายการยา" → แก้ไข → **บันทึกรายการยา**
2. แท็บ "สำรองข้อมูล" → **ดาวน์โหลด cart-list.js**
3. ใน GitHub repo นี้: **Add file → Upload files** → ลากไฟล์ `cart-list.js` ที่ดาวน์โหลดมา → **Commit changes**

ทุกเครื่องที่เปิดหน้าเว็บจะได้รายการยาใหม่อัตโนมัติ และ GitHub เก็บประวัติทุกครั้งที่แก้
